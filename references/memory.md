# 可修正的认知档案

## 存储选择

首次需要持久化时确认用户希望只在对话中保留摘要，还是保存到指定的本地目录或已连接服务。用户已指定位置和范围就直接使用，不重复询问。不得因为当前有代码仓库就把私密反思写进仓库。

没有写入工具或权限时提供可复制摘要，明确尚未保存。只在写入成功后报告位置。普通聊天不自动搜索其他聊天、邮箱或笔记；按用户授权范围读取有关记录。

若选择本地目录，可用 `preferences.md`、`sessions/YYYY-MM-DD-<unique-id>.md`、`observations/<id>.md` 和 `experiments/<id>.md`；获授权保存月度回顾时可用 `reviews/YYYY-MM.md`。这些是按需生成的用户数据，不是技能发布文件。使用用户时区，同日多条记录使用不同 ID，写前读已有文件，保留无关内容。不要为没有数据的类型创建空档案。

## 最小记录内容

| 类型 | 必需内容 |
| --- | --- |
| 偏好 | 语言、已明确的时区、记录授权范围、回避话题，以及用户明确选择的表达风格和推送设置；仅保存实际表达的偏好 |
| 对话摘要 | ID、时间、主题、必要的事实摘要、用户自己的解释、待解问题、可定位的来源 |
| 认知观察 | ID、创建／更新时间、情境范围、假设、支持证据、反对证据、未知项、用户反馈、状态 |
| 小实验 | 所关联的假设、用户选择的行动、观察指标、回访日期（若约定）、结果与修正 |
| 月度回顾 | 回顾时段、材料覆盖范围、来源、主要观察及其状态、用户修正；只在获授权保存时生成 |

来源可为实际会话 ID 与消息位置、文件路径与段落，或“用户于某日期回述，原记录不可访问”。没有原文时用转述，不伪造引号、链接或日期。支持和反对证据尚无时写“暂无／未检索到”，不补造内容。

默认保存最小摘要，不保存完整原始聊天和无关第三方细节。尊重“今天不记录”；不要在其他文件中间接保存该次内容。

## 假设的生命周期

使用 `待验证`、`暂有支持`、`已修正`、`已撤回` 状态。多个相互独立的情境和用户反馈可以增加支持，但不把次数当成人格结论的阈值。单个事件只能作为该事件的线索。

发现反例时记录它如何限制假设的适用情境。用户否认时保留其修正，不固守原推断；有必要时标记已撤回。旧观察未修改不代表仍成立，回访先确认当下适用性。

更新记录时简要标明何时、为何改变；不让历史版本继续作为当前结论参与摘要。用户要求删除时，按范围处理源记录及受其影响的摘要、索引和派生观察。报告实际删除范围与无法控制的副本，不承诺删除宿主聊天历史或备份。删除隐私请求优先于保留修订轨迹。

## 小实验示例（虚构）

假设：在低风险技术选型中，不明确结束条件可能延长比较时间。

实验：用户选择下一次可逆选型时限时比较，再制作最小原型。

观察：是否更容易开始，以及原型是否暴露了原先比较无法解决的信息。

回访：询问体验和意外结果；若未执行，了解实际情境，不推断用户缺乏自律。
