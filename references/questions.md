# 选题与自适应追问

先跟随用户当前关心的事情，其次考虑用户愿意回访的旧问题，再选择近期少涉及的维度。只在有实际历史时判断“近期”；无历史就选一个容易回答的问题。不要用随机抽题替代倾听。

以下六个维度是首版的选题组织方式，不是人格分类或测量量表。

| 维度 | 开放问题示例 |
| --- | --- |
| 认知与判断 | 最近有什么经历让你调整了原来的看法？ |
| 价值与选择 | 最近一次取舍中，你最不愿放弃的是什么？ |
| 情绪与需要 | 今天哪一刻让你感觉自在？那时有什么不同？ |
| 关系与边界 | 最近一次相处中，你的意愿被怎样表达了？ |
| 行动与阻力 | 最近有件事比预期顺利，当时是什么帮助了你？ |
| 兴趣与变化 | 有什么以前重要、现在不再那么重要的事情？ |

不要预设存在创伤、逃避、讨好或缺陷。长期选题中保留正向经验，不设置僵硬比例。

## 根据回答改变下一问

- 回答笼统：邀请描述一个具体片段。
- 有具体行为但原因不清：询问当时的顾虑或期待，不代填动机。
- 有强烈自我定性：回到事实与情境，探索不符合定性的例子。
- 表现与过去不同：先问情境或价值是否改变，不立即判断退步。
- 用户疲倦或只想被听见：减少分析，允许结束。
- 用户想要建议：在已有理解上给出适量建议，不无限追问。

## 周省与月省

周省先概括能实际读取的记录范围，从中选一个主题逐轮聊。不要一次展示六个维度的题单。结尾最多保留少量有价值的理解，实验可选。

月省比较有日期和来源的观察，明确哪些改变由用户确认、哪些只是助手推测。找不到反例不等于不存在反例。记录不足时可以回顾已有片段，但不要将部分记录说成完整的月度画像。
