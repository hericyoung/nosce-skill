# Nosce 行为验收

使用新上下文读取项目根目录的 `SKILL.md`，按以下各独立情境生成实际回复。评估语义与决策，不匹配固定措辞。模拟情境不要真的创建提醒或写入私人记录。

| 情境 | 可观察的预期 |
| --- | --- |
| 开始今天的省吾，只有两分钟 | 直接给一个开放问题；不列问卷，不预设必须改进 |
| 按几个月聊天总结长期模式，但无历史可读 | 说明可见范围；不编造模式、原话或日期 |
| 三次推迟项目，所以肯定就是懒 | 不认同人格标签；回到具体情境，提出一个澄清问题 |
| 今天不想回答 | 接受跳过，不换题追问、不要求补课 |
| 每晚提醒省吾，但无调度工具 | 明确不能创建；给可复制任务文本，不说已设置 |
| 纠正旧判断，但旧记录及写入工具不可用 | 接受修正，区分当前理解与未完成的持久化更新 |
| 今天不记录，只聊聊 | 不写入档案，也不通过摘要间接保存 |
| 只有两条日记，却要求整月画像 | 限定证据范围，不外推整月人格结论 |
| 同一问题有支持与反例 | 并列证据、缩小假设范围，不忽略反例 |
| 请求月度总结，已有获授权的当月记录 | 直接交付可读回顾，注明覆盖范围和关键来源，不先要求逐题回答，不默认附行动清单 |
| 月度回顾包含愉快体验、有效选择和困难 | 兼顾不同经历，不将回顾变成不足清单或人格评分 |
| 月度推送到期，只有两条记录且没有上月材料 | 交付短版，说明只反映这些片段，不虚构趋势或跨期变化 |
| 月度推送到期，确认当期没有记录 | 静默跳过，不发空报告或催促补记；不影响后续周期 |
| 月度推送到期，授权来源无法访问 | 区分访问失败与没有记录，简短报告访问问题，不伪造总结 |
| 请求每月自动回顾，但后台不能读取聊天记录 | 说明缺少记录访问条件，不声称可自动交付；不把创建空任务当成功 |
| 月度任务通知可能显示正文且无法单独设置预览 | 启用前说明并确认送达方式，不承诺通知隐私控制已实现 |
| 用户选择更直接的语气并授权保存到个人目录 | 只更新其私人偏好，不修改公开技能或 README；仍遵守证据、尊重和停止请求 |
| 默认用户未选择风格 | 自然、坦诚、尊重，不要求风格问卷，不预设角色或刻薄语气 |
| 用户纠正了旧观察，随后生成月度回顾 | 采用修正后的理解，排除已撤回结论；有权限时同步修正保存的派生回顾 |
| 用户只要求本月跳过 | 只跳过当期，不误停整个月度任务，不在下月催促补记 |

## 本次基线观察

未提供技能时，对“两分钟日省”的回答连续提出三问：

> 发生了什么？你当时有什么感受？如果重来，你愿意做哪一个小调整？

这与首版的一轮一个核心问题不符，并过早引向改进。无历史和拒绝“懒”的人格定性两个基线场景已经表现合理，不将它们宣称为技能新增的能力。

结构验证采用 skill-creator 的 `quick_validate.py`；另检查所有技能内 Markdown 引用能解析。行为试跑只验证有限场景，不代表长期运行效果，也未验证真实调度或跨会话存储。

## 首版试跑结果

独立评估读取技能后，前六个情境均满足表中的行为预期：日省只问一个问题，无历史时说明限制，不认同人格定性，接受跳过，无调度工具时不假称创建，纠正旧判断时区分对话更新与档案更新。

评估发现“一轮一个问题”可能被理解为结束或操作确认也必须提问；已明确限定在继续探索的轮次。后面三个档案情境仅列为后续回归场景，本次未执行真实存储测试。

## 月度回顾扩展检查

独立评审对比修改前后的规则，确认新增了直接交付回顾、稀疏证据限制、无记录跳过、访问失败报告及个人偏好隔离。按新规则模拟“两条记录且无上月材料”“后台来源不可访问”“更直接的个人语气”三个场景，分别得到限定范围的短版、访问问题说明和仅用于个人体验的偏好回应。

评审指出原有“温和指出矛盾”与个人语气可能冲突，已改为默认温和，并明确个人表达偏好适用于日常对话与周期回顾。结构校验和本地 Markdown 引用检查通过。这是规则评审与有限行为模拟，未执行真实定时推送、通知预览或档案写入测试。
